Logic Comparison (Step 3)

Comparing visual depth and boolean redundancy between the two requested implementations.

Nested Structure

Groups conditions hierarchically. Checks age boundaries once, then evaluates internal variables. More efficient for scaling.

If-Elif-Else Ladder

Flat structure. Re-evaluates age conditions on every line (Redundant). Easier to read for simple logic chains.

Structure A: Nested If

if is_public_holiday:
    return 25
else:
    if age < 12:
        return 30
    elif 12 <= age <= 17:
        if is_weekend: return 55
        else: return 45
    else:
        if is_student: return 60
        else: return 90

Structure B: If-Elif Ladder

if is_public_holiday:
    return 25
elif age < 12:
    return 30
elif 12 <= age <= 17 and is_weekend:
    return 55
elif age >= 18 and is_student:
    return 60
# ... (redundant age checks)

Step 5: The "Shadowing" Bug Experiment

What happens if we check for public holidays LAST instead of first? Use the toggle to break the logic.

Analysis: When the holiday check is moved to the bottom, demographic rules (which are also true) catch the execution first. A 22-year-old student on a holiday is charged R60 instead of R25 because the program stops at the first "True" result.
